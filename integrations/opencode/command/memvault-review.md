---
description: Review pending MemVault memory drafts (approve / edit / reject)
---

Follow the memvault review flow with the MemVault MCP tools: list pending
drafts with `list_inbox`, then for each one judge it against its source
snippet and either approve, edit or reject it via `review_memory`. Never
approve content you cannot verify from the snippet. Finish with a short
tally: approved / edited / rejected / left pending.
